### What were the most challenging parts of this phase and how did you overcome them?
Ans. The most challenging part of this phase, for me, was the WALA framework and Java itself. To understand WALA, it took me a few days of reading code, trace structure of the project and watching WALA tutorials. The process was complicated, because there are not many tutorials, also very difficult to find. And for Java, I have already forgotten many delicate concepts, for example, interface, dependency injection, design patterns, etc. Since then, I have not used this language for so long. I found myself a bit nervous and overwhelmed that I have to implement an even harder concept (Static Analysis) for Java. Luckily, I understood some basic knowledge of program analysis, so it was ok to continue learning them without losing hope.

To overcome these challenges, and calm myself down a bit.I try my best to explore more common ground topics around these subjects(not completely related topics), for instance, I read about the history of Java versions or some history of SDK vendors or even review my Java course from 2 years ago. After I gained confidence back, I found myself understanding WALA more easily and having fun researching it. I ran some examples, got more output and got more knowledge.
